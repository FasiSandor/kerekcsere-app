# KERÉKCSERE

Időjárás-alapú kerékcsere figyelő PWA.

## Fő funkciók
- 14 napos Open-Meteo előrejelzés
- automatikus téli/nyári gumicsere-javaslat
- fagy- és hótrend figyelés
- helyválasztás vagy GPS
- nyári/téli gumi állapot mentése
- böngészőértesítés
- mobil/PWA felület

## Technika
Next.js + TypeScript, Vercel, Open-Meteo.

## Következő kör
Valódi háttér-push és napi szerveroldali figyelés.
